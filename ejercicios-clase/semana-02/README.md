# Laboratorio 02 - Configuración del entorno

Para crear el entorno virtual se utilizó el comando:
- python -m venv venv en la terminal.

Para activarlo en Windows: 
- venv\Scripts\activate.bat

Las dependencias del proyecto se guardaron en requirements.txt con el comando:
- python -m pip freeze > requirements.txt

Cualquier persona puede reproducir el entorno creando un nuevo entorno virtual e instalando las dependencias con:
- python -m pip install -r requirements.txt
